Fixes recursive BIOS discovery and the incorrect “Needs BIOS / firmware” blocker on R4 and Ridge Racer PS1. Folder scans now register PS1/PS2 BIOS and PS3 firmware by content, search deeper folders, preserve valid manual selections, and repair stale paths. OpenBIOS build outputs and PS2 DVD-player firmware are excluded from automatic BIOS selection. Informational recomp setup notes no longer block Play.

Fixes the in-app PPSSPP fast-forward toggle and game-speed slider. Slider edits survive across frames and are saved on release; keyboard, controller, touch and toggle inputs no longer overwrite each other. Held fast-forward clears on pause, focus loss or controller disconnect. Pacing and audio reset when speed changes.

Adds **31:9** alongside 21:9 and 32:9. Choose **Auto** backend for a compatible wider 3D view: SwanStation for PS1 and PCSX2 for Ridge Racer V beyond 21:9; PPSSPP uses its European-disc camera patches. Rave Racer, RR6 native and RR7 use the physical display’s shape in fullscreen. RR6 now matches its projection to that actual shape even when a different fixed ratio was selected, preventing distortion. **Some emulator patches still stretch 2D menus/HUD; this is not universal unstretched-HUD support.** Unsupported regions/backends retain their supported aspect with bars instead of a stretch-only fallback.

Download **one runtime package for your operating system** below, extract it, and run Marathon. The emulator and native backends are included and install automatically on first launch, without separate emulator downloads. `START_HERE.txt` is inside each package.

- **macOS Apple Silicon:** [Download RidgeRacerMarathon-macos-arm64.zip](https://github.com/channelramble/RIDGE-RACER-MARATHON/releases/download/v0.2.3/RidgeRacerMarathon-macos-arm64.zip)
- **Windows x64:** [Download RidgeRacerMarathon-windows-x64.zip](https://github.com/channelramble/RIDGE-RACER-MARATHON/releases/download/v0.2.3/RidgeRacerMarathon-windows-x64.zip)
- **Linux x64:** [Download RidgeRacerMarathon-linux-x64.tar.gz](https://github.com/channelramble/RIDGE-RACER-MARATHON/releases/download/v0.2.3/RidgeRacerMarathon-linux-x64.tar.gz)

The Complete packages include SwanStation, PCSX-ReARMed, PPSSPP and MAME cores, standalone PPSSPP, PCSX2 and RPCS3; Windows also includes standalone MAME and Xenia Canary, and Linux includes Xenia Canary. RR6 native and Fukami are now included on all three desktop platforms, R4 setup kits on macOS/Windows, and Rave Racer native on all three platforms. The Mac RR6 and Rave Racer builds require macOS 14+; Fukami requires macOS 27+. No separate RR6 install or manual linking is needed. Every payload is pinned and checked against its SHA-256 hash. Existing backend installations, settings and saves are preserved.

Controller support includes gamepad navigation throughout Marathon, a live controller test, steering/pedal/dead-zone/player settings, and configurations for the supported emulator and native-port backends. Hold Guide + Start to return to Marathon; Back + Start is available where the operating system reserves Guide.

On macOS, holding a gameplay or navigation key no longer opens the accent-character picker. Text entry is enabled only while an editable field has focus.

**Bring your own game files.** No game images, extracted disc files, BIOS or console firmware are included. PCSX2 needs your PS2 BIOS and RPCS3 needs official PS3 system software. R4’s included setup kit still downloads build tools and compiles from your disc on first run. Rage Racer PC and Linux R4 remain upstream downloads because they publish no redistribution license. RR1 requires a local source build; the bundled emulators remain available. See the exact platform inventory in the bundle details below.

The `rrm-source-*` files are matching emulator/dependency source archives and are **not needed to play**. `source-manifest.json` records their provenance; `SOURCE-README.txt` explains extraction, including any split archives. `SHA256SUMS.txt` covers every release download. See [bundle details](https://github.com/channelramble/RIDGE-RACER-MARATHON/blob/v0.2.3/docs/BUNDLED_BACKENDS.md).

Validation includes a 93-check UI run with the real PPSSPP core (about 59 fps normal → 175 fast-forward → 59 normal; 118 at 200% → 59 at 100%), recursive-scan fixtures, actual MacBook BIOS discovery, 31:9 adapter checks, controller tests, hostile/corrupt bundle fixtures, app startup on all three operating systems, first-run offline import of every included backend and loading each libretro core. This does not establish gameplay compatibility for every game/controller combination. High-refresh frame generation and RR7 ultrawide retain the limitations documented in the README.

The macOS app is ad-hoc signed, not notarized: after the first blocked launch, use System Settings > Privacy & Security > Open Anyway. The Windows executable is unsigned: SmartScreen may require More info > Run anyway. Marathon supports macOS 11+ and Linux glibc 2.35+, but individual external backends can require newer operating systems, drivers or the Visual C++ x64 runtime.
